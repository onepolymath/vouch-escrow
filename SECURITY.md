# Security

Vouch has not been audited, and it's capped at 1,000 USDT or USDC per deal for that reason.

If you find a problem, please open a private security advisory on this repository
(Security tab, "Report a vulnerability") rather than a public issue. Include what you did, what
you expected and what happened. I'll answer as soon as I can.

There is no bug bounty.
